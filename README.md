# Russell De Barber — concept website

Next.js/TypeScript conceptsite voor Russell De Barber in Nijverdal.

## Belangrijk
- Alle boekingsknoppen verwijzen naar Russell zijn bestaande externe agenda: `https://res.afspraakmaken.online/?p=appointment&compid=19835657`
- Er wordt geen eigen reserveringssysteem nagebouwd.
- Openingstijden, adres en telefoon zijn overgenomen uit de aangeleverde bedrijfsinformatie.
- Diensten en prijzen staan bewust als concept/placeholder totdat Russell zijn definitieve lijst aanlevert.
- Rechtsonder staat `Concept - Voorstel`.

## Lokaal starten
```bash
npm install
npm run dev
```
